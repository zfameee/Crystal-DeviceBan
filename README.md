# Crystal-DeviceBan

Purpur 1.21.11 plugin for blocking a connection fingerprint.

## Важное ограничение

Обычный Minecraft-клиент не передаёт серверу настоящий Hardware ID (серийник диска, MAC-адрес, UUID материнской платы и т.п.). Поэтому **чистый серверный плагин не может гарантировать бан именно физического устройства**.

Этот проект использует SHA-256 от IP-адреса подключения. Сырой IP в `bans.yml` не хранится. Это означает:

- смена IP/VPN может обойти блокировку;
- несколько игроков за одним NAT могут попасть под один отпечаток;
- это не настоящий HWID-ban.

Для настоящего HWID-подобного решения нужен обязательный клиентский мод, который создаёт идентификатор устройства и передаёт серверу. Такой идентификатор также можно подделать, если клиент контролируется нарушителем.

## Команды

- `/crystaldeviceban <player> [reason]` — заблокировать текущее подключение игрока.
- `/deviceunban <fingerprint>` — снять блокировку.
- `/deviceinfo [player]` — показать отпечаток и статус.

## Сборка

Требуется JDK 21 и Maven:

```bash
mvn clean package
```

JAR появится в `target/Crystal-DeviceBan-1.0.0.jar`.

Положите JAR в `plugins/` и перезапустите Purpur 1.21.11.

Purpur 1.21.11 публикует `purpur-api:1.21.11-R0.1-SNAPSHOT`; Paper API для этой версии также документирован официально.
